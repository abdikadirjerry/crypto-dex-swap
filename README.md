# Crypto DEX Swap Terminal (`ts-crypto-dex-swap`)

A cyberpunk-themed decentralized exchange (DEX) token swap interface featuring simulated exchange rates, slippage controls, and live transaction feeds built with React, TypeScript, and Tailwind CSS.

## Features

- **Cyberpunk AMM Terminal:** Neon-accented dark trading interface.
- **Dynamic Token Conversion:** Real-time exchange rate calculation between crypto assets (ETH, USDC, SOL, BTC).
- **Slippage Tolerances:** Configurable slippage tolerance toggles (0.1%, 0.5%, 1.0%).
- **Transaction Feed:** Live logging of completed protocol token swaps.

## Setup & Running

1. Clone repository & install dependencies:
   ```bash
   cd ts-crypto-dex-swap
   npm install
   ```
